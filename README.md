# validador-hooks

Skill de Claude Code que valida hooks de reels/shorts con la escalera de 5 niveles (básico → nicho+acción → temporalidad → historia → experiencia+historia+meta) y muestra una interfaz con lo que le falta y propuestas por nivel.

## Instalar

```bash
git clone https://github.com/soyabrahamarriaga-lang/validador-hooks ~/.claude/skills/validador-hooks
```

Uso: "valida este hook: ..."
